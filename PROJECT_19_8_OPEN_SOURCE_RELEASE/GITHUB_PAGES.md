# GitHub Pages – PROJECT 19

## Repository
Create a public repository, e.g. `project-19`.

## Upload
Upload:
- index.html
- README.md
- LICENSE
- versions/

## Activate the website
GitHub → repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

The exact public URL is assigned by GitHub after deployment.

## Updating PROJECT 19
Keep the newest stable public build as `index.html`.
Before replacing it, copy the previous build into `versions/`.
