# PROJECT 19

**Open-source experimental 3D geometry lab**

PROJECT 19 explores interactive geometry in the browser: the five Platonic solids, dualities, the golden ratio (φ), pentagram geometry, Flower of Life, Metatron's Cube, and animated construction sequences.

## Start

Open `index.html` in a modern browser.

For a public website with GitHub Pages:
1. Create a new GitHub repository (for example `project-19`).
2. Upload the contents of this folder to the repository root.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will provide the public Pages address after deployment.

## Project principles

- Mathematical/geometric statements should be distinguished from symbolic or spiritual interpretations.
- Symbolic material is presented as experimental interpretation, not as established scientific fact.
- The project is intended for exploration, learning, modification, and creative experimentation.
